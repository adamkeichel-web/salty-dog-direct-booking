# Salty Dog & Co. Direct Booking

Official website repository for Salty Dog & Co. vacation rentals in Navarre, Florida.

## Branches

- `main` — production-ready releases only
- `staging` — safe testing and review before launch

## Planned integrations

- Beds24 for property inventory, rates, availability, and Airbnb/Vrbo synchronization
- Stripe for secure direct-booking payments
- Cloudflare Pages for website hosting

The booking integrations are intentionally disconnected until they are individually configured and approved.
